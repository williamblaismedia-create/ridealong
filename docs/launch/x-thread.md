# Fil X / LinkedIn (5 posts) — accompagner le post 1 de la vidéo verticale

1/ Every browser MCP has the same blind spot: you can't see what the agent is doing, and when it hits a login or a "Pay $49" button, your only option is to kill it.
So I built Ridealong. Watch your AI browse a real Chrome, live. Grab the wheel anytime. [vidéo]

2/ It's an MCP server for Claude Code (MIT). Claude drives a real Google Chrome; you open one link on your Mac or phone: H.264 stream, Claude's cursor, a journal of every action.

3/ Manual mode = your clicks, keys and scroll go straight into the page. Nothing you type is stored, logged, or visible to Claude. Perception tools refuse to run while you hold the wheel. There's a test for it.

4/ Before a payment, a send, a delete: Claude calls ask_approval. A card shows up on your phone. Approve or Deny. The tool waits. Tap an element to point Claude at it. Type a line, he hears it.

5/ One command to run it locally, a Docker image, or an always-on server with a tunnel. Console errors, network, real tabs, stable refs for the agent.
