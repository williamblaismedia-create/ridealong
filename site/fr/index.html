Un navigateur piloté par votre IA. Montez à bord, reprenez le volant quand vous voulez.

Ridealong est un serveur MCP open source pour Claude Code. Claude pilote un vrai Google Chrome ; vous ouvrez un lien et vous le regardez en direct, vous pointez, vous mettez en pause, vous approuvez les étapes à risque ou vous prenez le volant depuis votre téléphone. Puis vous le rendez.

claude mcp add ridealong -- npx -y -p ridealong-mcp ridealong
Voir sur GitHub

Licence MIT. Tourne sur macOS, Linux ou Docker avec Node 20. 133 tests. Un vrai Google Chrome, pas un navigateur sans tête.

Trois gestes qu'aucun autre MCP navigateur ne vous donne.

Regarder en direct

Un flux H.264 encodé par le GPU du vrai Chrome, environ 150 ms derrière. Le curseur de Claude glisse vers chaque cible avec une onde au clic ; un journal garde chaque action et son heure.

10:41:10 type textbox « Email »

Sans capture

La saisie en Manuel est relayée à Chrome et jamais retenue. Les outils de perception refusent de tourner pendant que vous tenez le volant. Les champs mot de passe n'exposent jamais leur valeur. Des tests le garantissent.

Liens signés, expirants

Liens signés HMAC, 30 s à 1 h, portés par le fragment d'URL pour ne jamais atteindre l'historique ni les journaux. Un appareil apparié garde un jeton de 30 jours. Un secret à changer pour tout révoquer.

Boucle locale par défaut

La vue live écoute sur 127.0.0.1. Vous décidez comment l'exposer : un tunnel Cloudflare, un VPN, ou rien du tout.

Des réponses directes.

Qu'est-ce que Ridealong ?

Un serveur MCP open source pour Claude Code. Il pilote un vrai Google Chrome par le protocole Chrome DevTools et le diffuse en direct vers une page que vous pouvez regarder, pointer, mettre en pause, approuver ou reprendre depuis votre téléphone.

Quelle différence avec Playwright MCP ou Chrome DevTools MCP ?

Ceux-là laissent un agent agir dans un navigateur. Ridealong ajoute l'humain : une vue live, une porte d'approbation, un mode Manuel sans capture, des pointages et messages vers l'agent, plus les erreurs console, les requêtes réseau, les vrais onglets et des références stables dans la transcription.

Ce que je tape en Manuel est-il visible par Claude ?

Non. La saisie est relayée directement à Chrome et n'est jamais stockée, journalisée ni exposée au modèle. Les outils de perception refusent de tourner pendant que vous tenez le volant, et les champs mot de passe n'exposent jamais leur valeur. Une suite de tests le garantit.

Ai-je besoin d'un serveur ?

Non. Une commande le lance sur la machine que Claude pilote. Docker et un serveur toujours allumé avec tunnel sont documentés pour regarder de n'importe où.

La vue live a-t-elle besoin d'un GPU ?

Non. Avec ffmpeg, Ridealong utilise NVENC, VideoToolbox sur macOS ou libx264 logiciel, selon ce qui existe. Sans ffmpeg il diffuse des images JPEG à la taille de votre écran.

Comment les liens sont-ils sécurisés ?

Signés HMAC, expirant après 30 secondes à 1 heure, portés par le fragment d'URL. Un appareil qui a ouvert un lien valide garde un jeton de 30 jours, donc l'adresse nue fonctionne. Changer le secret révoque tout.

Ça marche avec d'autres clients MCP ?

C'est un serveur MCP stdio standard, donc tout client qui parle MCP peut utiliser les outils. Le canal instantané pour les messages et approbations est une fonction de Claude Code ; les autres clients les reçoivent au bas du résultat d'outil suivant.
